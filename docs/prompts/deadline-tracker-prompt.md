# AI Prompt: Deadline Tracker Template

Use this prompt to generate a deadline-tracking spreadsheet template and
calendar reminders for your insurance appeals.

## When to use this

After you have one or more denied claims and want to organize their deadlines
in one place.

## Prompt (copy and customize)

```
I need to track deadlines for insurance appeals. I have [number] denied
claims. Please generate:

1. A markdown table with columns:
   - Claim Number
   - Denial/EOB Date
   - Appeal Deadline (calculate as EOB date + 180 days, shown as YYYY-MM-DD)
   - Days Remaining (as a formula explanation)
   - Status (Draft / Submitted / Awaiting Decision)
   - Notes
2. Conditional formatting guidance: how to highlight rows where the deadline
   is overdue (past) or approaching within 14 days.
3. Calendar reminder text I can copy into Google Calendar or another app:
   one event per claim, scheduled on the deadline date, plus a reminder event
   14 days before each deadline.
4. A short "good cause" paragraph I can adapt if I miss a deadline.

Use placeholder claim numbers like [CLM-XXXXX] and today's date as [YYYY-MM-DD]
so I can fill in real values myself.
```

## What to do with the output

- Copy the markdown table into your notes app or convert it to a spreadsheet.
- Set the calendar reminders as specified.
- Review your tracker weekly — set a recurring reminder for yourself.
- If any deadline passes, use the good-cause paragraph in your appeal letter.
